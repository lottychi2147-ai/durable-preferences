# 路線圖

這是研究規劃，不是已實作功能或交付時程承諾。

## 已完成的 v0.2.0

結構化偏好核心、快慢雙路徑、即時更正、暫時例外、精確去重、indexed compile、
快照、舊庫複製遷移、色圖、Skill 及本地測試。

## 接下來優先驗證

1. **真實訊息辨識：**建立人工標註的多情境資料集。除總準確率，單獨報告誤把玩笑當真、漏掉更正、指代錯人等。
2. **端到端宿主：**至少兩種模型／宿主，在新聊天與壓縮後確認資料載入及回答遵循。分開報告兩者。
3. **高噪聲控制：**預先固定反例、種子與門檻，不只追求通過既有 16 題。
4. **圖像記憶對照：**先定語法與評測，再比較資料＋圖、像素 codec、視覺讀圖。
5. **規模與治理：**大量 overlays、多寫入、同步衝突、可撤回的派生資料、刪除傳播與去重儲存。

## 暫不承諾

完整人格湧現、主觀意識、任意聊天 App 自動安裝、圖片比文字必然更省，以及無限時間固定儲存。
