# RFC-0001｜邀請共研：AI 圖像記憶應該如何編碼、累積與讀取？

大家好，我是這個專案的發起者紀順文。

這個專案的起點是：AI 不一定需要記住十年裡每一餐的日期，卻應能保留對一個人飲食與互動風格的理解。
我想用「概念的顏色逐漸累積」描述經驗如何形成長期傾向，而不是永遠重讀聊天紀錄。

現在已經有 v0.2.0 的偏好狀態引擎、Skill、色圖輸出與可重跑測試。
它修復了季度好評無法累積的問題，但自然語言分類與真實模型回答仍未驗證。
圖片原生編碼與視覺模型讀圖，更是希望大家一起研究的方向，不是已完成的結論。

## 想邀請大家討論

- 圖像應該是資料本體、視覺索引，還是狀態的另一種表示？
- 如何把喜愛方向、熟悉度、證據信心、近期改變和當次例外分開？
- 如何維持穩定的概念身份，讓圖片可局部更新、可遷移、可版本控制？
- 給 AI 看圖與直接讀結構化資料，哪些任務可能真的有差別？
- 如何設計不偏袒任何方案的測試？如何測十年稀疏經驗與後來的改變？
- 有哪些相關實作、論文或反例值得比較？請附來源，不用只給宣傳分數。

## 參與方式

歡迎用中文或英文分享設計草圖、合成範例、實驗腳本、失敗案例與資料格式提案。
可以質疑圖像路線；「什麼情況不該用圖」也歡迎。
請不要上傳真實私密對話或個人記憶資料庫。

本專案的核心問題不是「讓記憶圖看起來漂亮」，而是：
**如何讓 AI 從長年零散的經驗形成可靠傾向，又在使用者改變時跟得上。**

方法與目前能力請先看 README、docs/METHOD.md、docs/VALIDATION.md。
