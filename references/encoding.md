# 圖形記憶與機器資料

本版的記憶本體是三層數值狀態圖，不是把整段歷史文字裝成圖片。
每個節點由 owner / subject / namespace / scope / concept_id 定址。
`stable`、`candidate`、`overlays`、`familiarity_count` 和來源欄位分開保存。

- 色相：由 scope 的固定 SHA-256 雜湊映射到 0–359 度，領域一致即可，不是國際語意標準。
- 飽和度：對應目前傾向的絕對強度，不代表喜歡的方向。
- 正／負／中性／未知：另外用文字與數值標示，不單靠顏色。
- historical：另標示新鮮度，舊偏好不冒充最新確認。
- 圖形匯出包含相同 JSON 資料，經 HTML escape，避免標籤被執行。

AI 平常讀取 compile 的 JSON，不要求視覺能力。一般程式也可直接用同一份數值做候選排序。
第一版沒有訓練圖片解碼器，沒有證明「只讀色塊」比直接讀結構化資料更好。
圖像原生像素 codec、視覺模型直接讀圖屬後續比較實驗，不列入本次測試通過範圍。
